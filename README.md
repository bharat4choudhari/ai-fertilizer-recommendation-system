# 🌱 AI Fertilizer Recommendation System

An AI-powered fertilizer recommendation system that uses machine learning to recommend suitable fertilizers based on soil properties, crop type, temperature, moisture, and essential soil nutrients.

The project combines a **Random Forest classification model**, a **FastAPI backend**, and a simple **HTML, CSS, and JavaScript frontend** to provide fertilizer recommendations through an interactive web interface.

## 📌 Project Overview

Choosing an appropriate fertilizer is an important part of agricultural management. Different crops and soil conditions may require different nutrient combinations.

This project uses a machine learning model trained on a fertilizer recommendation dataset to predict a fertilizer category from user-provided agricultural parameters.

Users can enter soil and crop information, adjust environmental and nutrient values, and request a fertilizer prediction through the web interface.

### 🎯 Objectives

* Develop a machine learning model for fertilizer classification.
* Use soil and environmental parameters as model inputs.
* Compare Logistic Regression, Decision Tree, and Random Forest classifiers.
* Build a REST API using FastAPI to serve model predictions.
* Develop an interactive web interface using HTML, CSS, and JavaScript.
* Connect the frontend to the machine learning backend.

## ✨ Features

* **Machine Learning:** Uses a Random Forest classifier for fertilizer prediction.
* **Multiple Input Parameters:** Considers temperature, moisture, nitrogen, phosphorus, potassium, pH, soil type, and crop type.
* **Categorical Data Processing:** Uses One-Hot Encoding for soil and crop categories.
* **REST API:** Provides a prediction endpoint through FastAPI.
* **Interactive Interface:** Allows users to adjust input values using sliders and dropdown menus.
* **Model Comparison:** Evaluates Logistic Regression, Decision Tree, and Random Forest using classification metrics.
* **Reusable Model Pipeline:** Saves the trained preprocessing and classification pipeline using Joblib.

## 📊 Input Features

The model uses eight input features.

| Feature     | Description                     |
| ----------- | ------------------------------- |
| Temperature | Environmental temperature in °C |
| Moisture    | Soil moisture value             |
| Nitrogen    | Nitrogen nutrient value         |
| Phosphorous | Phosphorus nutrient value       |
| Potassium   | Potassium nutrient value        |
| PH          | Soil pH value                   |
| Soil        | Soil category                   |
| Crop        | Crop category                   |

The target variable is `Fertilizer`, which represents the fertilizer category the model learns to predict.

The dataset is located at:

`dataset/fertilizer_recommendation_dataset.csv`

## 🧠 Machine Learning Workflow

The machine learning component follows these steps:

1. Load the fertilizer recommendation dataset using Pandas.
2. Separate the input features from the target column.
3. Split the dataset into training and testing subsets.
4. Apply One-Hot Encoding to the categorical features `Soil` and `Crop`.
5. Pass the encoded categorical features and numerical features through a Scikit-learn preprocessing pipeline.
6. Train a Random Forest classifier.
7. Evaluate predictions using accuracy.
8. Save the complete trained pipeline using Joblib.
9. Load the saved model into the FastAPI application.
10. Generate predictions from user inputs received through the API.

### Random Forest Configuration

The current training script uses the following parameters:

| Parameter                | Value |
| ------------------------ | ----: |
| Number of estimators     |   300 |
| Maximum tree depth       |    10 |
| Minimum samples to split |    10 |
| Minimum samples per leaf |     2 |
| Random state             |    42 |

These are the current model configuration values in `ml/train_model.py`.

### Model Evaluation

The project includes a model comparison script that evaluates:

* Logistic Regression
* Decision Tree
* Random Forest

The evaluation metrics include:

* Accuracy
* Weighted precision
* Weighted recall
* Weighted F1-score

The comparison script is available in `test.py`.

Actual evaluation results may vary depending on the dataset, preprocessing, and train-test split. Run the script to reproduce the metrics in your environment.

## ⚙️ Installation and Setup

Follow these instructions to run the project locally.

### Prerequisites

Install the following software:

* Python 3.10 or later
* Visual Studio Code or another code editor
* A modern web browser

### Step 1: Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/bharat4choudhari/ai-fertilizer-recommendation-system.git
```

Navigate into the project directory:

```bash
cd ai-fertilizer-recommendation-system
```

### Step 2: Create a Virtual Environment

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use the environment's Python executable directly instead.

### Step 3: Install Dependencies

Install the required Python libraries:

```bash
python -m pip install fastapi "uvicorn[standard]" pandas scikit-learn joblib
```

These dependencies support the API, dataset processing, machine learning pipeline, and saved model.

### Step 4: Train the Machine Learning Model

Open the `ml` directory:

```bash
cd ml
```

Run the training script:

```bash
python train_model.py
```

The script loads the dataset, trains the Random Forest pipeline, evaluates its accuracy, and saves the trained model as:

`ml/saved_model.pkl`

**Important:** Run this command from the `ml` directory because the training script uses a relative path to locate the dataset.

### Step 5: Start the FastAPI Backend

Remain inside the `ml` directory and run:

```bash
python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

The API will be available at:

`http://127.0.0.1:8000`

To open the automatically generated interactive API documentation, visit:

`http://127.0.0.1:8000/docs`

Keep this terminal running while using the frontend.

### Step 6: Open the Frontend

Open the following file in a web browser:

`html/index.html`

You can also use the Live Server extension in Visual Studio Code.

Make sure the FastAPI backend is running before requesting predictions.

The JavaScript frontend sends requests to:

`http://127.0.0.1:8000/predict`

The current frontend is configured for local development, not a publicly deployed backend.

## 🔌 API Documentation

### Prediction Endpoint

**Endpoint:** `/predict`

**HTTP Method:** `POST`

**Content Type:** `application/json`

The API accepts the following input structure:

```json
{
  "Temperature": 25,
  "Moisture": 50,
  "Nitrogen": 40,
  "Phosphorous": 40,
  "Potassium": 40,
  "PH": 6.5,
  "Soil": "Loamy",
  "Crop": "Rice"
}
```

These values are an illustrative example. The input values and category names should be consistent with the dataset and the ranges supported by the application.

### Example Response

```json
{
  "status": "success",
  "predicted_fertilizer": "Predicted fertilizer category"
}
```

The returned fertilizer category depends on the trained model and supplied input values. The response above illustrates the response structure, not a guaranteed prediction.

## 🧪 Model Comparison

Run the model evaluation script from the `ml` directory:

```bash
python ../test.py
```

The script trains and evaluates Logistic Regression, Decision Tree, and Random Forest pipelines using a train-test split.

It prints a comparison table containing accuracy, weighted precision, weighted recall, and weighted F1-score.

The comparison is useful for understanding how different classification algorithms perform on the same dataset and split.
